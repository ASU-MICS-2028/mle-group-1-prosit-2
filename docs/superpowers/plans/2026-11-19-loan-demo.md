# NkwaPay Loan Demo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A public web app where a made-up borrower signs in with a phone number, asks for a loan, and sees the real scorer's decision with reasons; deployed on Cloud Run and recorded as a demo video.

**Architecture:** FastAPI in `app/` imports `src/scorer.score` unchanged, holds four made-up customer records, and serves a hand-built static page (HTML/CSS/JS, no framework). One container, deployed with `gcloud run deploy --source .`.

**Tech Stack:** Python 3.12, FastAPI, uvicorn, existing pinned stack; vanilla JS; Playwright (Node) + ffmpeg for the video.

**Spec:** `docs/superpowers/specs/2026-11-19-loan-demo-design.md`

## Global Constraints
- `src/scorer.py` is not modified. Every decision shown comes from `score()`.
- Nothing a borrower types is stored or logged beyond Cloud Run request logs.
- Never copy `data/zindi` or `data/worldbank` into the image or repo; only `data/models/scorer.joblib` goes into the image.
- Colours: maroon `#9D4444`, cream `#F6F2E9`, gold `#EFB05C`, sand `#E5DECF`, ink `#222222`, grey `#555555`. Headings Poppins; body `Candara, "Nunito Sans", system-ui`.
- Page always shows "Demo: made-up customers, no real money" and credits Zindi data and the Adinkra symbol authors (deck slide 16).
- GCP project `agroconnect-highlanders`, service `nkwapay-demo`, region `africa-south1` (fallback `europe-west1`), public, min 0 / max 2 instances.
- Fees: Kenya 2%, Ghana 3%. Kenya cut-off 0.021; Ghana `cutoff` is `null`.

## Review Focus
- Phone typed with spaces, dashes or a country code (`+254 712 000 001`, `0712-000-001`) → finds the customer (normalise to digits, map `254`/`233` prefixes to `0`).
- Amount empty, 0, negative, non-numeric or absurdly large (> 1,000,000) → friendly inline message, no API call; API returns 422 if called anyway.
- Requested amount above the limit → offer the limit and say "We can offer up to X, less than you asked for".
- A loan type from the other country (e.g. Kenya customer + `Type_3`) → API 422, UI never offers it.
- Double-tapping "Check my loan" → only one request in flight (button disabled while checking).

**Interfaces:**
- Produces: `CUSTOMERS: dict[str, dict]` keyed by normalised phone (`"0712000001"`, `"0712000002"`, `"0712000003"`, `"0244000004"`); each has `name, country, currency, summary: list[str], loan_types: list[{"code","label"}], history: dict` (the 10 history fields of `src.scorer.FIELDS` plus `New_versus_Repeat`).
- Produces: `normalise_phone(raw: str) -> str`.
- Produces: `GET /api/customers/{phone}` → `{phone, name, country, currency, summary, loan_types, first_loan: bool}`; 404 `{"detail": "not found"}`.
- Produces: `POST /api/apply` body `{phone: str, loan_type: str, duration: 7|14|30, amount: float (0 < amount ≤ 1_000_000)}` → `{decision, offer, requested, currency, repay, due_date (ISO), reasons, notes, probability, probability_source, cutoff}`.
- Produces: `GET /` serves `app/static/index.html`; `/static/*` serves `app/static/`.
